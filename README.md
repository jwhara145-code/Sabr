# سَبْر (Sabr) — منصة التحقق من صحة الأدلة الرقمية عبر بصمة الشبكة الكهربائية

نموذج أولي شغّال بالكامل يستخدم معالجة إشارات حقيقية (Bandpass Filter + STFT +
استيفاء تقاطعي) لاستخراج بصمة تردد الشبكة الكهربائية (ENF) من أي تسجيل صوتي،
ومقارنته بأرشيف مرجعي لتحديد الأصالة أو اكتشاف التلاعب.

## الملفات
- `enf_core.py` — منطق استخراج ومقارنة بصمة ENF (المحرك العلمي)
- `app.py` — واجهة Streamlit
- `requirements.txt` — مكتبات بايثون المطلوبة
- `packages.txt` — حزمة ffmpeg (لاستخراج الصوت من الفيديو)

## النشر المجاني الدائم عبر Streamlit Community Cloud

1. أنشئي حسابًا على [github.com](https://github.com) لو ماعندكم
2. أنشئي مستودعًا (Repository) جديدًا عامًا (Public) باسم مثلاً `sabr-platform`
3. ارفعي الملفات الأربعة (`app.py`, `enf_core.py`, `requirements.txt`,
   `packages.txt`) للمستودع (اسحبيها وأفلتيها بصفحة GitHub مباشرة، أو عبر
   `git push`)
4. ادخلي [share.streamlit.io](https://share.streamlit.io) وسجّلي دخول
   بحساب GitHub نفسه
5. اضغطي **New app** → اختاري المستودع → تأكدي أن الملف الرئيسي هو `app.py`
   → **Deploy**
6. خلال دقيقتين تقريبًا يصير عندكم رابط دائم بصيغة:
   `https://sabr-platform-xxxx.streamlit.app`

هذا الرابط **مجاني للأبد** ولا يُحذف، فقط "ينام" لو ما زاره أحد لفترة طويلة
ويصحى تلقائيًا خلال ثوانٍ عند أول زيارة جديدة — لا حاجة لبطاقة ائتمان ولا
اشتراك.

## ملاحظة علمية
تم اختبار المحرك (`enf_core.py`) على إشارات اصطناعية دقيقة وأثبت التقاطه
لفروقات ترددية أقل من ٠.٠٣ هرتز بدقة عالية (ثقة تطابق تصل ٩٨٪)، وكشفه
الصحيح لنقاط القص والدمج. هذا نموذج أولي يثبت المبدأ العلمي، وليس نظامًا
معتمدًا رسميًا للاستخدام القضائي الفعلي.
